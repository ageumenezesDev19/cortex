# Para ler depois

## Estruturas de dados persistentes

Estrutura que devolve uma versão nova em vez de alterar a antiga. É o que faz
desfazer sair de graça, e é a ideia por trás de boa parte das bibliotecas de
estado imutável.

## Bancos vetoriais

Guardar significado em vez de palavra levanta uma pergunta nova: como achar o
vizinho mais próximo sem comparar com todos. HNSW é a resposta que apareceu com
mais força.

## Tipografia em telas pequenas

Quase tudo que se sabe sobre entrelinha e comprimento de linha veio do papel.
Vale conferir o que continua valendo quando a coluna tem 320 pixels.
