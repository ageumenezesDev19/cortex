# Atalhos do editor

## Movimentação

Pular para a definição de um símbolo e voltar sem tirar a mão do teclado é o
que mais economiza tempo num arquivo grande.

## Edição múltipla

Selecionar todas as ocorrências de uma palavra e editar as três de uma vez
evita o erro clássico: trocar duas e esquecer a terceira.

## Busca no projeto inteiro

Procurar por expressão regular com filtro de extensão. É assim que se acha a
origem de uma constante cujo nome é genérico demais para um grep simples.
